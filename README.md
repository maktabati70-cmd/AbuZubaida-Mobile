# مركز أبو زبيدة للتتبع والرصد — نسخة الجوال

تطبيق أندرويد مستقل يعمل دون كمبيوتر: يجلب الأخبار من 168 مصدراً و24 قناة تيليغرام، ويترجمها إلى العربية، ويكشف الأحداث النوعية، ويضعها على الخريطة مع رصد مضيق هرمز وباب المندب، ويصدر الإنذار المبكر، ويعدّ الملخص اليومي.

## البناء
كل رفع إلى المستودع يبني ملف APK تلقائياً عبر GitHub Actions. تجده في تبويب **Actions** ← آخر تشغيل ← **Artifacts**.

لتوقيع ثابت (حتى تنزل التحديثات فوق التطبيق القديم) أضف أسرار المستودع نفسها المستعملة في QuranRadio:
`KEYSTORE_BASE64` و `KEYSTORE_PASSWORD` و `KEY_ALIAS`.
